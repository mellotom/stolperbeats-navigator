# stolperbeats-navigator

travelers guide for stumbling across the universe: a one-page reference for **making sound machines stolperbeats**, the shuffled drum trigger sequencer. every control on the panel, patterns and pattern edit, shuffle, timing and feeling, outputs and clocking, envelopes, banks, cv and linear, midi in and out, the sd card, expander and specs.

source: the stolperbeats quickstart and online manual (firmware 162).

not affiliated with making sound machines.
